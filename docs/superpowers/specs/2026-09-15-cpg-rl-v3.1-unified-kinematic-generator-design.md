## 0. 為什麼要改（2026-09-15 重看 trip21 錄檔的結論）

L 報告（`task7/docs/results/L_原廠步態參考錄製_2026-09-09.md`）與 v3 spec §7 有兩處結論錯了，錯因是**整檔平均**把起停與靜止段一起平均掉：

| 動作 | 之前的結論 | 錄檔逐秒攤開後 |
|---|---|---|
| 平移 | 移動側兩腿踏步、另一側輪胎側滑；模擬站不住 | **四腿都踏**（2.1 Hz）。移動側每步側向 +35～+48 mm、擺動 0.10 s；另一側**抬起原地重放**（機身座標 dy ≈ 0、擺動 0.20 s，機身在它擺動時被帶過去）。輪：移動側 fl +4／bl −3 rad/s，另一側 ≈ 0 |
| 邊走邊轉（弧線） | 純差速輪行、不踏步、差速比 1.3–1.7 | 穩態偏航 18–52°/s（不是 7–13）。**內側前腿持續踏步** 2.2–2.4 Hz、抬 18–26 mm、側向重放 40–80 mm；快弧線時對角的外側後腿也踏（0.5 倍頻次）。內側前腳往中線收 60–100 mm、內側後腳往外撐 30–50 mm。輪速外前／內後差 4–5 倍 |
| 原地轉 | 對角一對同相踏步、另一對站姿 | **四腿都踏**（2.5 Hz）：主導對角對抬 23 mm，另兩腿抬 16 mm；相位 {fl 0, br 0.06, fr 0.25, bl 0.59}（左轉） |

模擬站不住平移的真正原因：v3.0 產生器只讓移動側兩腿 `active=1`，另一側釘死 → 身體要側移只能靠釘死輪側滑。是實作漏掉，不是物理做不到。

**四種動作是同一套運動學**：每腳每週期在地面上的位移 D_k = T·(v + ω × r_k)。純前進位移全在 x，輪子滾得掉，所以不抬腳；平移／原地轉／弧線有 y 分量，輪子做不到，所以抬腳。錄檔的每步位移方向全部符合這條公式（左轉 fl (−21, +39)、br (+16, −25)；左移 fl (−23, +38)、bl (+20, +29)）。

分析腳本（scratch，將收進 `inference/ref_extract.py`）：擺動事件法 = 足端 FK 高度相對 1 s 滾動最低點抬 > 12 mm、時長 0.04–0.35 s。

## 2. 產生器

指令 cmd = (vx, vy, wz)，單位 m/s、m/s、rad/s。沒有離散模式，全部是 cmd 的連續函數。

### 2.1 運動學

腳 k 的站姿位置 r_k = (x_k, y_k)（機身座標，由 `max_model` 的 HIP_X／ABAD_TO_HIP_X／ABAD_TO_FOOT_Y 加站姿足端偏移算出；前腳 x ≈ +0.43、後腳 ≈ −0.42、y ≈ ±0.17 m）。步週期 T = 1／f。

```
D_k = T · (vx − wz·y_k,  vy + wz·x_k)         # 每週期地面位移 (m)
vec_k = (KX · D_k.x,  D_k.y)                  # 踏步位移：x 分量大部分交給輪子
KX = 0.3                                      # 錄檔：原地轉 fl 每步 dx −21 mm，公式全量 −73 mm
```

`foot_targets` 沿用：swing 往 +vec_k、stance 往 −vec_k、抬高只加在 swing。四腿共用同一條 vec_k 公式就是「無側滑蟹行」：stance 腳相對機身以 −v 移動，swing 腳每週期補回 +D。

### 2.2 活動度（誰抬腳、抬多高）

```
a_lat   = clip(|vy| / 0.08, 0, 1)
a_turn  = clip(|wz| / 1.3, 0, 1)
a_wheel = clip(|vx| / 0.25, 0, 1)
s4      = max(a_lat, a_turn · (1 − a_wheel))            # 四腿踏步（平移、原地轉）
s_arc   = a_turn · a_wheel                              # 弧線：內側前腿 ＋ 對角外側後腿
```

每腿活動度 s_k：

| 情境 | 腿 | s_k |
|---|---|---|
| 四腿踏步（s4） | 主導腿 | s4 × 1.0 |
| | 次要腿 | s4 × 0.7 |
| 弧線（s_arc） | 內側前腿 | s_arc × 1.0 |
| | 對角外側後腿 | s_arc × 0.5 |
| | 其餘 | 0 |

s_k = max(四腿項, 弧線項)。主導腿：平移＝移動側兩腿；原地轉＝主導對角對（左轉 fl+br、右轉 fr+bl）。0.7 與 0.5 是錄檔抬高比（23 mm 對 16 mm）與踏步頻次比。

抬高 lift_k = s_k × LIFT，LIFT 名目 0.023 m，命令值再加 Z_SAG 0.036（kp250 撓度，不變）。純 vx 時 s_k 全 0，不抬腳；`u_mode` 混合變數由 max_k s_k 取代（仍保留 1 s 斜率限制，避免指令跳變時目標跳）。

### 2.3 相位

四腿一組偏移（週期分數），以左向為基準、右向左右鏡像（fl↔fr、bl↔br）：

| | fl | fr | bl | br |
|---|---|---|---|---|
| 原地左轉 PH_TURN | 0 | 0.25 | 0.59 | 0.06 |
| 左平移 PH_LAT | 0 | 0.19 | 0.51 | 0.72 |

弧線用 PH_TURN（弧線是原地轉的主導對角對在 vx 大時的殘留：錄檔快弧線 fl 0、br 0.21）。vy 與 wz 同時非零時，每腿偏移取 PH_LAT 與 PH_TURN 依 a_lat：a_turn 權重的圓周插值。偏移目標改變時每步限速 0.02 週期。

方向鏡像的判定：平移看 sign(vy)，旋轉看 sign(wz)。

### 2.4 步頻與 duty

名目 f = 2.0 Hz、duty 0.5（RL ω ±28%、抬高 ±40% 不變）。原廠 2.5／2.1 Hz、duty 0.6–0.8 是 kp 250 做不到的（v3 spec §7 掃描），留在 `REF["factory_*"]` 對照。G0 掃 duty {0.5, 0.6, 0.7}。

### 2.5 輪速

```
diff_k  = (vx − wz · sign(y_k) · L_eff/2) / r          # 差速，L_eff 0.375（資料擬合值）、r 0.096
gate_k  = 1 + (1 − a_wheel) · (1 − 2·dom_k)            # 原地轉：主導對角對 0、另兩輪 2（力矩守恆）；vx 大時全部 1
wheel_k = diff_k · gate_k + a_lat · LAT_WHEEL_k · Ω_lat(vy) + res_k
```

- dom_k ∈ {0, 1}：原地轉主導對角對。錄檔左轉 fl/br ≈ 0、fr +4.1／bl −4.1。
- LAT_WHEEL：左移 fl +1.0、bl −0.67、其餘 0（右移鏡像），Ω_lat = 3.3 × |vy|/0.06 rad/s。這條運動學推不出，照錄檔抄。
- res_k：RL 輪殘差，**速度偏移 ±2 rad/s**（kd 1.0 下等價 ±2 N·m），取代 v3.0 的 ±20% 比例殘差。
- 控制律：`wheel_ctrl`（kd 1.0、前饋 0.13、死區 0.3），模型 `scene_flat_mjx_v3.xml`。`wheel_pos` 參數保留但預設 False；`_v3p` 模型不刪、不用。

### 2.6 弧線姿態偏移

站姿足端 y 目標加 s_arc × POSTURE_ARC：內側前腳 −0.06 m（往中線）、內側後腳 +0.03 m（往外），其餘 0。REF 參數，G0 開關比較，沒幫助就設 0。
