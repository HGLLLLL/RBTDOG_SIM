## 2. 三個改動

### 2.1 `t_abadbias`：ABAD 慢漂

```
abad_dev = q12[ABAD] − STANCE_Q12_j[ABAD]                    # (4,) rad
abad_ema = abad_ema + BIAS_EMA · (abad_dev − abad_ema)        # BIAS_EMA = 0.02，與 roll_ema 同一個 1 s 低通
t_abadbias = W_ABADBIAS · Σ abad_ema²                         # W_ABADBIAS = 30（W35）；預設 W 為 0
```

- 2.5 Hz 週期擺動經 1 s 低通後幅度剩約 6%（一階低通 k=0.02 在 2.5 Hz 的增益 0.064；±25° 擺剩 ±1.6°，平方乘 30 每步 0.02，可忽略），**只罰慢漂不罰週期**。
- 量級：一腿 15°（0.26 rad）→ 每步 2.0；5° → 0.23；四腿各 3° → 0.33。對照 `t_yawrel` 滿分 8。
- **只在踏步時開**：乘 `u_mode`（不是 `k_post`）。攤帳發現直走時 policy 讓四腿常態外張 5°（輪行站姿，有 `r_stance` 管、ABAD 剛度隨機化下寬一點穩），那不是漂移，不該罰；原地轉、平移 `u_mode=1` 全開。
- `cyc_recenter=True` 下週期 delta 以站姿為中心，所以「偏離站姿」就是「偏離名目」；若日後改 `cyc_recenter=False` 要換成偏離 `q_des` 的低通。

### 2.2 `t_drift`：低頻速度漂移

```
v_err = (vb[0] − cmd[0], vb[1] − cmd[1])                     # 機身系
drift_ema = drift_ema + BIAS_EMA · (v_err − drift_ema)        # (2,)
t_drift = W_DRIFT · Σ drift_ema²                              # W_DRIFT = 40；預設 0
```

- 平移往後漂 0.08 → 每步 0.26，加上原本 `t_vx` 的 0.55，總共 0.81，超過它換到的側向進度分。
- 原地轉時兩軸指令都是 0，同時管住轉圈時的平移。
- 直走時低頻誤差本來就小（vxerr 0.06 含高頻），影響可忽略；§3.3 攤帳會量。
- 高頻 ±0.3 擺動被低通濾掉，不罰。

### 2.3 平移效率

`W_VYREL 3.0→6.0`、`P_VY 0.45→0.60`。其餘取樣機率不動（`P_VX 0.65`、`P_WZ 0.50`、`P_TURN_ONLY 0.35`）。
有 vy 指令的回合由 45% 提到 60%，回合組成會變，所以 `進度 yaw` 的天花板略降，停損線（§6）照舊 3.5 不改——它是「學不學得到」的門檻不是排名。

### 2.5 `t_headlin`：線性航向項（2026-09-16 下午加）

```
r_headlin = 1 − clip(|head_err| / HEAD_LIN_E, 0, 1)          # HEAD_LIN_E = 0.5 rad（29°）
t_headlin = W_HEADLIN · r_headlin                              # W_HEADLIN = 1.0（W35）；預設 0；加進 pos
```

與原地轉的 `r_yawlin` 同一個做法：高斯核外仍有斜率。`head_err` 沿用（gyro_z − wz 指令的積分，起走歸零）。
直走時 ≈ 1.0 常數、原地轉時 ramp 期累積的落後（−39°）讓它為 0，兩者都不影響梯度；只有平移／斜走那種「指令 wz=0 但慢慢轉掉」的情形有作用。

### 2.6 右轉週期＝左轉鏡像平均（2026-09-16 傍晚加，使用者決定）

`_sym_turn_cycles`：turn_left 與 mirror(turn_right) 做循環相關找相位差（實測 86°，對齊後相關 0.99；不對齊直接平均會糊掉），
對齊後平均成 sym_left，sym_right = mirror(sym_left)；hz 取平均。平移那對本來就是鏡像（`_mirror_cycle`），不動。
平均後四腿 ABAD 峰對峰 31／70／61／15（未乘 0.7）：**對角不對稱保留**，只拿掉左右兩次錄影的幅度差。
開關 `REF["cyc_turn_sym"]`（預設 False，`cycle_offsets` 在 Python 層選表 → v3.3 逐位元不變）；`W35["CYC_TURN_SYM"]=True` 由 env 自動打開，
所以 `weights=W35` 一個開關帶齊 reward 與產生器設定；驗收工具用 `--preset v35`。
零動作名目（10 s、seed 0）：原廠增益左 +14→+11、右 −8.5→−8.1，都 3.3–3.5 s 倒（本來就會倒）；kp250 右轉 −21→**−33**，左 +29 不變。
`cyc_recenter=False` 的絕對模式 `CYC_QMEAN` 沒做對稱版（v3.x 都用 recenter=True）。

### 2.4 程式形式

```python
W = dict(..., W_ABADBIAS=0.0, W_DRIFT=0.0, W_HEADLIN=0.0, HEAD_LIN_E=0.5)   # 預設 0 → v3.3 reward 逐位元不變（0.0·x 精確為 0）
W35 = dict(W, W_ABADBIAS=30.0, W_DRIFT=40.0, W_HEADLIN=1.0, W_VYREL=6.0, P_VY=0.60, CYC_TURN_SYM=True)
env = v3.DualModeEnv(weights=v3.W35)                 # v3.5；v3.5f = DualModeEnv(gains="factory", weights=v3.W35)
```

- `info` 加 `abad_ema (4,)`、`drift_ema (2,)`；`T_KEYS` 加 `t_abadbias`、`t_drift`、`t_headlin`；`metrics` 加 `abad_bias`（四腿 |ema| 最大值，度）、`vx_drift`（drift_ema[0]，m/s）、`head_deg`（head_err，度）給 progress 印。
- obs 不變（88）。golden 只比 obs／reward／qpos／ctrl，預設權重下全部不變。

### 9.1 沒到目標的共同原因：**二次懲罰在接近目標時自己消失**

`t_drift = 40·Σema²`：漂 0.08 時每步 0.26（設計時算的），漂到 0.038 只剩 **0.058**，對照每步總 reward ≈ 8.6 等於沒有。
`t_abadbias = 30·Σema²`：6.3° 時約 0.6／步，同樣推不動最後一段。
→ 想收到 0.02／5° 必須**換形狀**（線性或障礙項，接近目標時仍有斜率），不是把權重乘大（乘大會讓遠離目標時過度懲罰，重演 v3.2「靠不動避罰」）。
`t_headlin` 是線性的，它就是三項裡唯一大幅見效的（航向 −32 → +4.5）。**這條是本輪最實用的一般結論。**

### 9.4 ★ 右轉弱的根因：質心偏心 × duty 0.5 的兩腳支撐（2026-09-16 夜查清）

**不是**先前推測的「右轉錄檔幅度小兩成」——那個已被 §2.6 鏡像修掉，實測產生器現在對稱：
右轉腿 ctrl vs 鏡像(左轉) 差 **3e-8 rad**、輪名目差 **0**；相位差是四腿一致的半週期（`theta` 錨在腿 0，會整段抵銷）。

真因是**模型質心不在兩條支撐對角線的中間**（`scene_flat_mjx_v3f.xml`，站姿整機質心 y **+1.5 mm**，佔半寬 210 mm 的 0.7%；後膝左右質量差 3.3 g／0.39%）：

| | 左轉支撐的 FR+RL | 右轉支撐的 FL+RR |
|---|---|---|
| 質心到支撐線垂距 | +2.1 mm | **−4.8 mm**（2.3 倍，且反向） |
| 零動作側傾平均 | 0.42° | **1.37°** |
| 零動作倒在第幾步 | 172 | **157** |
| policy 偏航 | +80.8 ±21 | **−64.1 ±34** |
| policy 抬腿（甩動對角） | 49／60 mm | **72／101 mm** |
| policy 膝峰 | 45 | **57** |

→ 右轉抬更高、出力更大、晃更兇，淨旋轉反而更少＝**動作預算被拿去救平衡**。

**平移不受影響（左右只差一成）**：原地轉 `duty 0.50` 同時只有兩腳（純對角）著地；平移 `duty 0.70`、四腿交錯相位
→ 平均約 2.8 腳著地，1.5 mm 偏心沒有槓桿。實測零動作平移 vy 左 +0.157 對右 −0.162（**差 3.1%**）、
policy 104% 對 117%、膝峰同為 36、|a| 同為 0.227。剩下的一成屬 policy 局部解差異。
（平移另一個**未解**問題：抬腳只有 6–13 mm，原廠 16–22 —— 仍是滑步，v3.5 沒處理。）

**★ 這是 sim2real 風險不只是美觀**：policy 學到的是針對「質心偏左 1.5 mm」的方向專屬補償，實機偏心方向不會一樣。
現行 DR 隨機每個 body 質量 ±10%（間接擾動質心約 ±1 mm），但那是乘在偏心的名目上，**系統性偏移沒被洗掉**。
→ v3.6 建議：①DR 加**橫向質心偏移**（零均值 ±5 mm）②訓練時**左右鏡像增強**（需定義 88 維 obs／24 維動作的鏡像對映）。
