**成功。** 斜坡重訓後，機器人**爬得上 15° 上坡、也走得下坡，而且走得很直**——解決了零樣本測試「10° 就往後滑倒、還會走歪」的兩個問題。

## 關鍵設計（生效驗證）
- **平台→斜坡過渡 + distance-emergent curriculum**：機器人先走平地再上/下坡、越走越陡 → 學得起來。
- **三個地雷修復**（rel_h=z−gz、觸地用 gz、g_c 固定）：讓斜坡上的獎勵/跌倒判定正確。
- **防走歪 reward**（純直走指令 + 有界橫向懲罰 −0.8·(1−e^(−y²/0.1)) + r_yaw 加權）：側偏從 >1m 降到 ~0.2–0.4m。
- **有界獎勵 + nan 防護**：修掉先前無界 −y² 導致的訓練 nan。
