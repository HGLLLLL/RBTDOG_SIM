## 觀察

- 新模型能穩定跟隨全向指令、上下坡與凹凸皆不跌，直走略快於舊模型（2.67 vs 2.44 m）。
- **可學抬腳 `gc` 收斂在 ~0.06–0.07 m，略低於舊的固定 0.08**，並非往上限 0.15 衝。代表在此 reward 下，策略認為中等抬腳已足以應付 8cm 凹凸；「加了凹凸就會自己抬更高」的假設只部分成立（有在調，但幅度不大）。若要更明顯的高抬腳，需另加腳部離地獎勵或提高凹凸/擾動強度。

# 與 2026-07-15 相同實驗（新 16 維模型跑一次）

腳本：`task4/analysis/terrain_compare2.py`（課程/圖表/鏡頭沿用 `terrain_compare.py`，只換 16 維模型）。同課程、同 `cmd=[0.8,0,0]` 原生直走 → 可與 `../2026-07-15/` 逐檔對照。

## 舊（直走專用 12 維）vs 新（全向 16 維）

| 實驗 | 舊 07-15（terrain v1，只訓直走+y_pen） | 新 07-16（terrain2，全向16維，無 y_pen） |
|---|---|---|
| slope（5/10/15° 山丘×3） | 爬過三座山丘、**不跌**、側偏 **2.71m** | 爬到 x=22.3m（幾乎全程）、側偏 **3.69m**、**43.9s 跌** |
| rough（3/5/8cm ×3） | 全部通過、**不跌**、側偏 **2.91m** | 過所有凹凸(x=17.2m)、側偏 **7.05m**、**33.5s 跌** |
| gc 抬腳 | 固定 0.08 | 學到 ~0.072 |

## 關鍵解讀（誠實）

**新模型在「純開環直走長跑道」這個特定測試上，反而比舊模型更會漂、且最後走出加寬跑道而跌。** 這不是 bug，是**設計取捨的直接結果**：

- 舊 v1 是**直走專家**：只訓 `cmd=[vx,0,0]`、且有**絕對側移懲罰 `y_pen`** 把它牢牢釘在中線 → 開環直走很穩，但**完全不能轉向/橫移**（給 wz/vy 會崩）。
- 新 16 維是**全向通才**：訓練涵蓋 vy/wz、且**移除了 y_pen**（你的指示）。給它直走指令時，它只壓「瞬時側速/偏航率」，殘留誤差會隨時間累積成緩慢航向漂移；**又沒有絕對位置/航向回授**（你也明確不要外掛 sensor）→ 長跑道上漂移比舊模型大，凹凸地形擾動更會加速偏航。3s 時側偏僅 0.05m，是**隨距離累積**到 30–45s 才明顯。
- 兩者**地形通過能力其實都在**：新模型一樣爬完所有山丘、過完所有凹凸，只是最後漂出跑道。

**這正好印證 07-15 README 的預告**：盲走直線要靠上層 odom/IMU 航向回授修正。差別是——**新的全向模型「吃得下」wz 航向修正指令，舊 v1 一給 wz 就崩**。所以要做真機直走任務，新模型才是對的底座（task5 的 RC/odom 外圈控制器可閉環修正），開環直走的漂移由外圈解決，不該要求底層盲走自己走絕對直線。
