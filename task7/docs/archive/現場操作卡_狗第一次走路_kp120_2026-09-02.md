## 1. 這一趟和 trip15 只差一件事：**`d_step` 從 0 變成 0.10**

| | trip15（跑過）| **這趟** |
|---|---|---|
| `d_step` | 0.0（原地）| **0.10（前進）** |
| `x_off` | +0.04 | **−0.04** ← 符號相反 |
| `g_c` | 0.06 | **0.08** |
| kp / kd / z_sag / ω | 120 / 1.0 / 0 / 1.4 | **完全相同** |
| 步態長度 | 4 秒 | **7 秒** |

`g_c` 從 0.06 提到 0.08 的理由：離地從 22–32 mm 變成 **59–75 mm**，
力矩幾乎沒變（模擬 41.9 vs 41.9）。**開迴路沒有回授，離地餘裕值得多買一點。**

## 8. ★ 這趟終於問得了那一題

**前後腿有沒有在互相對抗？**

模擬的前進步態量到前輪往後滾 2.5–2.7 m、後輪往前滾 2.2–2.3 m，
在四輪平均裡幾乎抵銷（`docs/CPG步態_完整結果_2026-08-27.md` §2）。
原地踏步問不了這題（`d_step=0`，沒有推進），**前進步態才問得了。**

⚠️ **不要看收工表的「淨轉動」** —— 那是總量、前後抵銷會把它藏起來。
要用 `w` 欄的 position 逐輪拆，我這邊做。

⚠️ 另外：原地踏步三趟拆出來是「站立相佔八成、空轉只佔兩成」，
和舊文件寫的相反。前進步態的比例可能又不一樣，**不要沿用**。

## 9. 這趟不做的事

- **不加長步態。** 7 秒已經涵蓋 ~5 個步態週期，足夠判讀；而且空間有限。
- **不動 `wheel_kd`。** 模擬顯示 `kd 1.0` 比現行 0.5 好（滑動 −27%），
  但不要和「第一次走路」疊在一起 —— 出事會分不清是誰造成的。
- **不調 ω 到 2.0。** 那個換算是 82%，而且前進速度提升要用力矩換。先走起來再說。
