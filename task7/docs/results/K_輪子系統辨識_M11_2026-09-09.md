# K. 輪子速度伺服系統辨識（M11，trip20，2026-09-09）

- 條件：狗墊高、四輪離地、腿洩力；四輪同時驅動；200 Hz；τ = kd·(v_des − v) + τ_ff，kp = 0
- 五個協定全部跑完、零中止、**kd 1.0 沒有抖振**（M10 的 2.0 才自激）
- log `logs/m_logs_trip20/M11_2026-09-09_15{2733,2844,2943,3037,3126}.json`；擬合 `inference/wheel_sysid.py`；全表 `outputs/wheel_sysid_trip20.md`

## 0. 一句話

**輪子是一個「幾乎沒有動態」的速度伺服：延遲 5–7 ms、時間常數 ≤ 10 ms（200 Hz 量不出更小），
行為完全由摩擦決定 —— 動摩擦 0.13–0.15 N·m、黏滯 0.012–0.016 N·m·s、起動門檻約 0.25 N·m；
追蹤率 = 1 − (τ_f + b·v)/(kd·v)，kd 1.0 時 3 rad/s 為 0.94，公式與實測對到 0.01。**

## 3. 對輪行模式的直接結論

1. **輪子可以當理想速度源建模，只留摩擦與 1–2 tick 延遲。** 不需要致動器網路。
2. **實機控制律定案**：kd 1.0（無抖振、追蹤率 0.94 @ 3 rad/s）＋ 前饋 τ_ff = 0.13·sign(v_des)。這樣穩態誤差只剩黏滯項 0.015·v/1.0 ≈ 1.5%。
   起走時要越過 0.25 N·m 的起動門檻：kd·v_des + τ_ff ≥ 0.25 → v_des ≥ 0.12 rad/s 就夠（有前饋）。
3. **模擬器要改的三件事**：輪關節加 `damping 0.015`；速度伺服改成 kd 1.0 ＋ 前饋（現在 `KD_WHEEL 0.5` 純阻尼、`KP_WHEEL 60` 是原廠 RL 的位置環，我們不用）；
   動作延遲 1–2 tick；obs 輪速加 0.1 rad/s 雜訊。靜摩擦門檻用「|v_des| < 0.3 rad/s 視為 0」在指令端處理，不進物理。
4. **四輪不對稱**：fr 的摩擦與雜訊都最小（τ_f 0.11、noise 0.05），fl/br 最大（0.16／0.13）。隨機化範圍 τ_f 0.10–0.18、b 0.005–0.03 蓋住。
5. 這是**空載**數字。承重滾動的摩擦（輪胎變形、地面）與打滑要等「輪行模式」上機那趟（腿站著、只給 vx）才量得到；那趟同時是模擬輪地接觸的 G1。

## 4. 限制

- 200 Hz 取樣，延遲與時間常數都只到 5 ms 解析度；掃頻上限 4 Hz（振幅 1.5 rad/s 的安全考量），高頻滾降沒量到。
- 低速 0.5 rad/s 那級只有 fr 有動，靜摩擦門檻是由「不動」反推的下界，不是掃出來的。
- kd 只測 0.5 與 1.0；1.0 到 2.0 之間的邊界沒掃（M10 定 2.0 自激）。
