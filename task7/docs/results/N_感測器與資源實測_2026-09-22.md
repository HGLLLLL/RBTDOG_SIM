### 感測器的實體接法（裝置列舉交叉佐證）

| 感測器 | 怎麼接 |
|---|---|
| 光達 ×2 | Orin NX 的兩張 CH397 **USB 10/100 網卡**，各自獨立網段（見 7.4） |
| 相機 ×2 | RK3588 的 MIPI CSI，`imx415 6-0037` 與 `imx415 7-0037`（I²C bus 6／7） |
| 超音波 ×2 | NX 的 CH9344 USB 多序列埠 `/dev/ttyCH9344USB{0,1}`，**115200 bps** |
| UWB | NX 的 `/dev/ttyTHS1`（Tegra 原生 UART） |
| GPS / RTK | RK 上 `gpsd -s 115200 -n -P NMEA /dev/ttyS4 /dev/pps0` —— **有 PPS 授時** |
| 機身 IMU | `robot_hal_node/imu_recv_thread` 讀進來，經 `/dev/shm/imu_central` 發布 |
| 馬達 | `can0`–`can3` 四條 CAN（各 0.05 MB/s，四條都在動） |

## 7.2　Camera

| 層 | 量到的 |
|---|---|
| 感測器 | **Sony IMX415**（`dmesg`：`imx415 6-0037`、`imx415 7-0037`），前後各一顆 |
| 原生擷取 | `rkcif` 節點，**3864×2192** 的 10／12-bit Bayer（約 **8.47 MP**，對得上手冊「800 萬」） |
| ROS2 topic | `sensor_msgs/CompressedImage`，前 **9.912 Hz**、後 **9.994 Hz**，QoS RELIABLE / KEEP_LAST(10) |
| **RTSP（實拉 `ffprobe`）** | **H.264、1920×1080、avg 25 fps**（`r_frame_rate` 30），`yuv420p`；前後兩路相同 |
| RTSP 伺服器 | `mediamtx`（`/opt/runtime/bin/mediamtx.yml`），`rtspAddress :8554`，另有 RTMP :1935 |
| 內參（NX 的 apriltag 標定） | `fx=791.50 fy=791.58 cx=1005.02 cy=560.12` ＋ 5 個畸變參數 |

**`/dev/video*` 有 42 個節點，不是 42 顆相機**：`rkcif` 22 個（MIPI 擷取，每條 lane 一個）、
`rkisp_*` 18 個（ISP 的 mainpath／selfpath／statistics／params／rawrd）、
`video-dec0` / `video-enc0` 兩個硬體編解碼。

## 7.4　LiDAR 等其他感測器規格

### 光達（兩顆同型）

| 項目 | 值 | 來源 |
|---|---|---|
| 型號 | **RoboSense `RSAIRY`** | `rslidar_sdk/config/config.yaml` 的 `lidar_type` |
| 線數 | **96 線** | 點雲 96 × 900 有序，且有 `ring` 欄位 |
| 掃描頻率 | **9.907 / 9.917 Hz**（標稱 10） | `ros2 topic hz` |
| 每掃點數 | **86,400** → **864 k 點/秒** | 96 × 900 |
| 每點位元組 | **26** | `x,y,z,intensity` f32 ＋ `ring` u16 ＋ `timestamp` f64 |
| 驅動的距離濾除 | `min_distance 0.2`、`max_distance 200` m | 設定檔（是驅動的濾除範圍，**不等於感測器規格**） |
| 水平視角 | `start_angle 0` → `end_angle 360` | 設定檔 |
| 時戳 | `use_lidar_clock: true`、`ts_first_point: true` | 設定檔（點雲時戳用光達自己的時鐘） |
| 空點 | `dense_points: false`（保留 NAN） | 設定檔 |
| `frame_id` | 前 `rslidar_head`、後 `rslidar_tail` | 設定檔／訊息 |
| 自帶 IMU | `imu_port 6688`，前 206.5 Hz、後 175.0 Hz | 設定檔／實測 |
