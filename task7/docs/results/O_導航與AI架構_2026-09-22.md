## 5.3　路徑規劃 / 導航 / 避障功能

**底座是 ROS 2 Nav2（navigation 版本 0.6.5），但三個 server 的 plugin 幾乎都換成廠商自己的 `navigo`。**

### 規劃（`planner_server`，`active`）

| plugin | 實作 |
|---|---|
| `GridBasedST` | 栅格搜尋（短程） |
| `GridBasedSL` | 栅格搜尋（長程） |
| **`ThreeDimTopoBased`** | `navigo_3d_topo_global_planner/Navigo3DTopoGlobalPlanner` —— **3D 拓樸圖規劃** |

平滑器用 nav2 內建 `nav2_smoother::SimpleSmoother`。
從 topic 名另可見 **Hybrid A\***（`hybrid_astar_exploration_points`、
`hybrid_astar_start_end_sampling_points`）、中線（`centerline_points`）與
**ESDF 歐氏距離場**（`esdf_cloud`，`esdf_resolution 0.05`、粗 0.4／細 0.2）。

### 控制（`controller_server`，`active`）

| plugin | 實作 |
|---|---|
| `FollowPathPP` | 純追蹤（pure pursuit） |
| `FollowPathPID` | PID |
| **`FollowPathLocalPlanner`** | **預設**（`default_controller_id`），廠商自己的局部規劃器 |

目標檢查 `general_goal_checker`；目標容差 **0.25 m / 0.05 rad**；BT 迴圈 50 ms。

### 決策（`bt_navigator`，`active`）

載入 **80 個以上 `navigo_*` 行為樹節點**，能力可直接從節點名讀出：
規劃與路徑編輯（`compute_path_to_pose`、`optimize_path_service`、`stitch_path`、`truncate_path*`）、
**自主探索**（`frtree_action` frontier tree、`compute_information_gain`、`is_exploration_completed`）、
**巡檢**（`select_patrol_goal`／`select_patrol_mode`）、
**重定位**（`generate_relocalization_goal`、`is_localization_status_satisfied`）、
**UWB 導引**（`compute_uwb_goal`）、視野判斷（`is_target_in_fov`、`generate_leading_rays`）。

**多路徑候選＋加權評分**（`multi_path_selector`）：最多 10 條候選，權重
安全 0.30／參考線偏離 0.30／平滑 0.20／效率 0.15／運動可行性 0.05；
快速剪枝：離障礙 ≥ 0.15 m、路徑 ≤ 10 m、曲率 ≤ 3.0 1/m、平均曲率 ≤ 1.0。

### 恢復行為（`behavior_server`）

`spin`、`backup`、`drive_on_heading`、`wait`（`navigo_behaviors/*` 實作）；
另有 `clear_costmap_service`、`clear_error`、`recover_invalid_goals`。

### 避障

| 層 | 內容 |
|---|---|
| Costmap | `global_costmap`、`local_costmap`、`local_costmap_controller` 三張；`consider_footprint: True`、`cost_scaling_factor 3.0`、`cost_scaling_dist 0.3` |
| **機身外形** | 足跡是矩形 **0.90 m × 0.36 m**（`[[0.45,0.18],[0.45,-0.18],[-0.45,-0.18],[-0.45,0.18]]`），另有 0.60×0.30 的組態；規劃器另用 `robot_radius 0.35` 做快速碰撞檢查 |
| `collision_monitor` | 停車多邊形 `PolygonStop` ＋ 減速多邊形（`action_type: slowdown`），來源 `scan`，`emergency_stop_timeout 5 s` |
| 速度層 | `velocity_optimizer` 節點 |
| 融合 | `fusion_lidar_cam_odom_app.yaml`：光達＋相機＋里程計；障礙點最低高度 −0.5 m、軟門檻高度 0.15–0.35 m、分割生點距離 8–20 m |
| 近場 | 超音波 ×2（10 Hz）補光達盲區 |

局部規劃器的設定檔變更紀錄裡明列「多級軌跡束生成」、「後退脫困」、「裁剪局部軌跡」、
「LocalPlanner footprint 碰撞檢測」→ 這些是已經迭代過的功能，不是初版。
