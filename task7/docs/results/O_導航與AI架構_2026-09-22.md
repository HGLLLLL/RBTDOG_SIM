## 5.2　建圖 / 定位功能

**定位**（`localization_params_loc.yaml`，這是設定檔自己寫的可選值）：

| 項目 | 值 |
|---|---|
| 目前模式 | **`LIO_UKF`** —— 點雲地圖定位（UKF 融合） |
| 可選模式 | `RTK_IO`（純 RTK）、`LIO_UKF`、`RTK_IO_LIO`（Faster-LIO 里程計）、`ODOM` |
| 更新頻率 | `frequency: 0.1` s → **10 Hz** |
| 用哪些量 | IMU ✅、GNSS ✅、**輪速 odom ❌**（`is_use_odom_: false`） |
| 配對 | NDT `DIRECT7`、`match_resolution 0.5`、`globalmap_voxel 0.12`、`cloud_voxel 0.15` |
| 收斂判定 | `match_score_thre 0.5`、初始化 1 次、連續 5 次、逾時 5 次 |

## 5.3　路徑規劃 / 導航 / 避障功能

**底座是 ROS 2 Nav2，但決策層是廠商自己的 `navigo`**（`ZG/nav2_params.yaml`）：

- `bt_navigator` 載入的 **plugin 全部是 `navigo_*`**（80 個以上 BT 節點），不是 nav2 內建那套。
  能力可以直接從節點名讀出來：
  - 規劃：`compute_path_to_pose`、`compute_paths_to_poses`、`compute_path_through_poses`、
    `optimize_path_service`、`stitch_path`、`separate/reseparate_paths`、`truncate_path*`
  - 控制／跟隨：`follow_path_action`、`progress_check`、`compute_control_error`
  - 恢復行為：`back_up`、`spin`、`wait`、`clear_costmap_service`、`clear_error`、`recovery_node`、
    `recover_invalid_goals`
  - **自主探索**：`frtree_action`（frontier tree）、`select_exploration_goal`、
    `compute_information_gain`、`is_exploration_completed`
  - **巡檢**：`select_patrol_goal`、`select_patrol_mode`
  - **重定位**：`generate_relocalization_goal`、`is_localization_status_satisfied`
  - **UWB 導引**：`compute_uwb_goal`
  - 視野判斷：`is_target_in_fov`、`generate_leading_rays`、`decompose_convex_regions`
- `default_controller_id: **FollowPathLocalPlanner**`；`global_frame: map`、`robot_base_frame: base_link`、
  `odom_topic: /odom/current_pose`、BT 迴圈 50 ms、`transform_tolerance 0.2`
- 目標容差：位置 **0.25 m**、朝向 **0.05 rad**
- **多路徑候選＋評分選路**（`multi_path_selector`）：最多 10 條候選，權重
  安全 0.30／參考線偏離 0.30／平滑 0.20／效率 0.15／運動可行性 0.05；
  快速剪枝門檻：離障礙 ≥ 0.15 m、路徑 ≤ 10 m、曲率 ≤ 3.0 1/m、平均曲率 ≤ 1.0
- **機器人半徑 0.35 m**；安全評價：安全距離 0.8 m、臨界距離 0.40 m
- 從 topic 名可見的規劃與軌跡生成：`hybrid_astar_exploration_points`、
  `hybrid_astar_start_end_sampling_points`（**Hybrid A\***）、`centerline_points`、
  **`esdf_cloud`**（歐氏距離場）、`pcd_overlay`；控制器兩套 `cs/ppc`（純追蹤）與 `cs/lpc`（局部路徑）
- 避障：`collision_monitor` 節點、`global_costmap`／`local_costmap`／`local_costmap_controller`
  三張 costmap、`velocity_optimizer`（速度層再最佳化）、
  障礙融合 `fusion_lidar_cam_odom_app.yaml`（光達＋相機＋里程計融合，
  `obstacle_point_min_height -0.5`、軟門檻高度 0.15–0.35 m、分割生點距離 8–20 m）
- 超音波 ×2 補光達的近場盲區（10 Hz）

> 待補（recon5）：`planner_server`／`controller_server` 的 **plugin 實際名稱與參數**
> （上一趟的 yaml 被截在 140 行）、costmap 的圖層清單與膨脹半徑、`collision_monitor` 的
> 多邊形與停車距離、行為樹 XML 的實際決策流程。

## 5.4　完成度、成熟度、適用場景與限制

**完成度（事實）**：導航、SLAM、LVIO、回充對位四個模組在 `alg_manager_arc_mid.yaml` 裡
**`enabled: true` 且 `default_launch: true`**，開機就起；`navigation` 的啟動參數是
`platform:=REAL robot_type:=zg`（有 `GAZEBO`／`XG`／`ZG` 三套參數檔，這台吃 ZG）。
節點全表裡 nav2 的 `planner_server`／`controller_server`／`bt_navigator`／`behavior_server`／
`collision_monitor`／`waypoint_follower`／`lifecycle_manager_navigation` 全在跑。
→ **這是產品化的成套導航，不是 demo。**

**成熟度的正面證據**：有迴路閉合、有 GNSS 因子、有多路徑評分、有三層 costmap＋碰撞監視器、
有恢復行為、有自主探索與巡檢、有 AprilTag 回充對位、有 UWB 導引。

**已經看到的限制（都有依據）**：

| 限制 | 依據 |
|---|---|
| **幾何退化沒有保護** | `use_degradation_detection_flag: false` → 長走廊、大空間、玻璃幕牆容易漂 |
| **不吃輪速里程計** | `is_use_odom_: false` → 靠 IMU＋光達＋GNSS；輪足打滑時少一個獨立來源 |
| **定位只有 10 Hz** | `frequency: 0.1` s → 高速移動時位姿更新偏慢 |
| **應用板算力已經吃滿** | Orin NX 待機 CPU 70%、loadavg 13.6（8 核超賣）、GPU 峰 99% → **要加自己的 AI 應用幾乎沒有餘裕**（見 N 報告 §1.3） |
| 室內沒有 RTK | GNSS 因子與 `RTK_IO` 模式在室內用不到 |
| 外參固定 | `estimate_extrinsic_flag: false`，撞擊或拆裝後要重跑 `/ota/calibration_results.yaml` 的校正 |

> 待補（recon5）：`/home/robot/robot_launch_log` 裡導航相關的錯誤樣態（成熟度的反面證據）、
> 生命週期是否全部 `active`。

## 6.1　AI 功能與技術架構

**兩條完全獨立的 AI 線**：

| | 感知 AI（應用板 Orin NX） | 運控 AI（運控板 RK3588） |
|---|---|---|
| 節點／行程 | `perception_jobs`（實測 CPU 46–52%、RSS 0.84 GB） | `mc_ctrl` |
| 功能 | 偵測、追蹤、分割、障礙融合 | 原廠運動控制策略 |
| 設定檔 | `perception/config/perception/{detection,segmentation,obstacle_detection}/*.yaml` | `/opt/export/rknn_model_crypto/`（**加密**） |
| 平台 | Orin NX GPU（待補證實） | **RKNPU**，實測走路時 Core0 7.4%、站著 0% |

**感知的三個子功能（設定檔檔名與內容）**：
1. **偵測** `detection/camera_imx415.yaml`、`camera.yaml`、`camera_usb.yaml`（三套相機來源），
   `imu_pitch_angle: 42`
2. **追蹤** `detection/track_config.yaml`：`frame_rate: 10`、`global_reid_frame_rate: 2`
   → **有 ReID（跨影格重識別），10 Hz 追蹤、2 Hz 全域 ReID**
3. **分割** `segmentation/lidar_range_seg_config.yaml`：光達距離影像分割，`resolution: 0.1 m/px`
4. **障礙融合** `obstacle_detection/fusion_lidar_cam_odom_app.yaml`：光達＋相機＋里程計

> 待補（recon5）：模型檔清單（`.onnx`／`.engine`）、類別表、輸入尺寸、信賴門檻。
