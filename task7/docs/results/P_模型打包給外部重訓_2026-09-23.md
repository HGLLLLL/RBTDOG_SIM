## 3. 重打包指令

```bash
PACK=task7/outputs/d1max_model_pack_$(date +%F); mkdir -p $PACK/task7/{model,inference,outputs,notebooks,weights,tests/data,docs/results}
cp task7/model/max.urdf $PACK/task7/model/; rsync -a --exclude __pycache__ task7/model/zgws $PACK/task7/model/
for f in rl_env_v3 rl_env_max max_model obs_max cpg_max leg_kin gait_baseline cpg_walk_max; do cp task7/inference/$f.py $PACK/task7/inference/; done
cp task7/outputs/ref_cmd_cycles.json task7/outputs/ref_gait_dataset.json $PACK/task7/outputs/
cp task7/notebooks/build_nb_v3.py task7/notebooks/cpg_rl_v3_{6f,7f,7bf}_colab.ipynb $PACK/task7/notebooks/
cp task7/weights/cpg_rl_v3_6f_params.pkl $PACK/task7/weights/
cp task7/tests/test_mjx_model.py task7/tests/test_rl_env_v3_golden.py $PACK/task7/tests/; cp task7/tests/data/rl_env_v3_golden.npz $PACK/task7/tests/data/
cp task7/docs/results/MJX模型對照_2026-08-27.md $PACK/task7/docs/results/; git rev-parse HEAD > $PACK/GIT_COMMIT.txt
# README.md 從上一包複製後改日期；然後 sha256sum 與 tar czf
```
