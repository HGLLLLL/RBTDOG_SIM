## 2. 現場改了什麼（都已 commit）

1. `--hold-max 15`／`--walk-max` 乾跑也要帶（承重預算 60 s）。
2. **`--wheel-mode kd1 --wheel-kd 1.0`**：外環 τ=1.0·(v_nom−v) 交驅動器 1 kHz 做，effort 只剩 wres＋週期表力矩。原因：無負載輪慣量太小，50 Hz 外環迴路增益 > 2 發散。之後每趟輪速峰 ≤ 3.5 rad/s。
3. v3 慢速力矩累計只算步態三段：`fl1` 在 kp 250 站立段每趟 4–5 筆孤立單筆尖峰（−50…−121，前後 −8…−26，同號），三趟連續誤觸。
4. `estop_max.sh` 殺程式清單補 M8–M11（之前漏列）。

## 3. 結論

- 狗端 numpy 堆疊與模擬一致：12 趟 0 摔、0 急停、退回 1 步／6000 步；推論＋產生器中位 2.0–2.2 ms（預算 10）。
- 原地轉達指令 90–100%，左右鏡像對稱（±42 vs 46）；直走貼指令。
- **平移是弱項**：v3.6f 的平移本來就是側滑（抬腳 4–10 mm），實機有側移但自轉 ±3–4.5°/s（左右反向、大小相同 → 產生器側向輪子圖案的偏航力矩，不是機器不對稱）；ABAD 命令釘止點 60% 步數、力矩 38–40（TMAX 50）、誤差 0.65（護欄 0.91）。
- 沒跑：⑦ 放大（0.15 平移、1.3 原地轉）、離吊帶。
