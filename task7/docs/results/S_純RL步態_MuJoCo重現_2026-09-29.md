## 2. 重現設定

- 模型 `scene_flat_mjx_v3f.xml`（腿 kp 60/120/120 kd 1.0 與他相同；輪 velocity 致動器 kv 由 0.1 改成他的 1.0；forcerange 150/33）。子步 0.005 s × 4。
- obs 由 MuJoCo 直接算（free joint 角速度＝機身系；重力向量 `Rᵀ(0,0,−1)`；關節按名稱映射到 PhysX 序）。onnxruntime 推論。
- 兩種模式：**ideal**（關節摩擦／慣量歸零＝他的訓練條件）與 **real**（含實機辨識的關節 frictionloss 1.85／1.5、輪 0.13、damping、armature）。
- 每指令先 1 s 零指令站定、再 8 s 指令，統計取指令後 1 s 起。抬腳口徑同 R 文件（足端 − 四足最低、> 8 mm 遲滯段）。

## 4. 判讀

1. **前進純輪行**：腿不動（誤差 0.1）、輪子 5.7／11 rad/s，vx 追到 106–109%。與原廠、與 v3.6f 相同。
2. **平移是真踏步**：四腿 2 步/秒、抬 14–43 mm（vy 1.0）；這是 v3.6f 一直做不到的。real 模式 vy 0.5 只追到 70%（關節摩擦吃掉），vy 1.0 追到 96%。輪側滑懲罰讓它學會踏步。
3. **原地轉靠輪差速**，偶爾踏步（0.1–0.4 步/秒）；wz 1.0（57°/s）追 98–103%。roll 峰 2–6.5°，比 v3.6f（3–4°）略大。推力下轉速掉到 57%。
4. **強健性夠上機**：延遲 2 步、雜訊、推力、三者合併都 0 摔。IMU 偏置沒隨機化（實機 pitch −1.2°／roll +0.6°），要在影子跟跑補測。
5. **護欄用量（real）**：ABAD 誤差峰 0.59（wz 0.5）、髖膝 0.35（延遲 1 步 vy 1.0）→ ×1.3 ＝ `--emax-abad 0.77`、`--emax 0.46`；膝 τ 峰 57（TMAX 70）、ABAD 44（50）、髖 36（50）；輪速峰 14；關節速峰 10.6。
6. **vy 1.0 現行護欄下不可部署**：命令角速度峰 18–20 rad/s（關節規格 19.9、`--vcmd-max` 16）。**第一次上機平移只到 0.5**（命令速峰 8–10）。
7. **命令會超出機構限位**：wz 0.5／1.0 有 11–19% 步、vy 1.0（延遲）19% 步至少一顆目標超限（Isaac 用 0.9 軟限位、罰項權重 0）。狗端一定夾 `LO12/HI12` 並記 `n_sat`。動作本身無界（|a| 最大 3.5 → 0.87 rad 偏離），狗端加 `|a| ≤ 3` 夾限當保險。
8. **站姿差 5.5 cm**：他的 default pose 機身高 0.485 m。M9 起身要起到他的姿勢（`stance_q12` ＝ 他的 default），不是我們的 0.54。

### 6.1 ③ 不動的根因：policy 的側向指令死區（不是實機問題）

- MuJoCo real 模式重跑 vy 0.3：**同樣不走**（vy 0.009、四腳無離地 > 8 mm、ABAD 只動 0.05 rad），policy 在兩個靜態姿勢間以 0.33 Hz 慢擺；加 1 步延遲一樣。
- 狗上指令切換後第一步的 `a_raw` 與模擬第一步逐維相差 < 0.1 → numpy 推論、obs 組裝、動作映射都對；差的是 policy 對這個指令本來就不踏步。
- 掃描（`outputs/rl_only/eval_rl_only_real_vy_sweep.md`）：|vy| ≤ 0.3 死區；0.35 起步（0.13）；0.4 → 0.21、0.5 → 0.35、0.6 → 0.47（≈ 指令 × 0.7 − 0.07）。護欄用量到 0.6 都在範圍內（ABAD 誤差 ≤ 0.33、命令速峰 ≤ 9.9）。
- 訓練端原因（`RL_only/*_env.yaml`）：`track_lin_vel_xy_exp` std 0.5 → vy 0.3 不動仍拿 exp(−0.36) ≈ 70% 追蹤獎勵，踏步的代價（關節偏差、動作變化）划不來；`command_threshold 0.1` 只縮放站立獎勵。vx 沒死區（純輪行零成本）。
- §3 表當初只驗 vy 0.5／1.0，操作卡把 0.3 寫成「真踏步」是沒驗過的外推 —— 已改 ③ 為 vy 0.5、⑤ 放大 0.6。

### 6.3 右轉塌陷的根因：policy 右轉策略貼著 ABAD 內收止點，狗的右低側傾把它推過去

- 轉向策略（模擬與狗上動作一致）：一對對角腿**內收**到機身下方當支點，另一對輪差速。右轉內收 FAR／RBL 到 +0.42／−0.37 rad，
  離 0.523 止點只剩 **0.10 rad**；左轉內收 FBL／RAR 到 −0.31／+0.22，餘裕 0.21–0.30。
- 模擬右轉對延遲、雜訊都穩（−22～−24°/s），但**重力側傾 1°** 或**摩擦 ×1.5** 就重現狗上的塌陷（−11～−15°/s、roll 5.6°、ABAD 到止點）；
  同樣擾動對左轉沒影響。狗每趟 READY 的靜態 roll 都是 +0.3～1.0°（右側低），方向正好是右轉會再往那邊傾的那側。
- 狗上 200 Hz 順序：1 s 起內收 → roll 慢慢 0.3 → 2.0°（3.5 s）→ fr ABAD 實際角超過命令（被機身壓進去，kp 60 只出 10–16 N·m）→ 5 s 碰止點 → roll 跳到 4.7°、偏航歸零。
- 加大指令 policy 改用踏步（後左腿 1–1.2 步/秒）、內收量降到 0.16–0.31：側傾 1–2° 下 −0.8 給 −31～−42°/s、−1.0 給 −57°/s。表：`outputs/rl_only/eval_rl_only_real_wz_sweep.md`。
- 根治要重訓（內收止點餘裕／地面側傾隨機化）。現場可做的：右轉直接跑 −1.0（乾跑先）；或把狗轉 180° 再跑 −0.5 分辨是地面斜還是狗本身偏。
