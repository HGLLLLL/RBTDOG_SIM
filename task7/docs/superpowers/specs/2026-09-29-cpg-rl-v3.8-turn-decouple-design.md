## 0. 動機（實機證據）

- trip23（2026-09-29）：同一個 v3.6f policy，原地轉 0.8 rad/s 擺動腿抬 15–27 mm、離地 0–8 mm、0.4–0.8 步/秒；1.3 rad/s 抬 32–36 mm、2.1 步/秒。lift 動作兩趟都頂在 +0.8（上限 1.0）。結果 `docs/results/R_v3.6f段⑦放大_2026-09-29.md` §2。

  1. 旋轉族走原廠週期表，ABAD／髖／膝三關節共用倍率 `clip(|wz|/1.3, 0.3, 1.2) × cyc_amp_turn`（`cycle_offsets`，:261），抬高跟轉速一起縮，撓度與地面不縮。
  2. 旋轉族沒有任何抬腳獎勵：`t_step`（每週期頂點）只乘 `_lat_weight`（:805）；`r_lift` 在週期表族因 `g_leg = step_gain(s_kin) = 0` 整項為零、無梯度。
- 平移側滑（抬 9–26 mm）的解法 v3.7 已設計（`cyc_lat_decouple`），v3.7f 訓完只因旋轉退步被否決；v3.7b（＋輪前饋＋`LIFT_NONNEG`＋鏡像增強）已設計未訓。

## 1. 範圍與驗收（使用者定）

- **範圍**：v3.8 ＝ W37B ＋ 旋轉族解耦（三選一選了「一次解決平移與旋轉」）。
- **模擬驗收（不達不上機）**：原地轉 0.8 擺動腿離地 ≥ 30 mm、偏航 ≥ 指令 85%；原地轉 1.3 偏航 ≥ ±80°/s；平移 0.12／0.20 ≥ 2 步/秒、抬 ≥ 25 mm、vy ≥ 80%；ABAD 命令飽和 < 5% 步；膝／髖／ABAD 力矩峰不超 v3.6f（43／31／40）；側傾 std ≤ 1.2°；3 種子 0 摔；鏡像後左右差 < 10%。

## 2. 名目產生器改動（`rl_env_v3.cycle_offsets` ＋ `realbot/gen_v3.py` 同步）

- 新 REF 鍵：`cyc_turn_decouple=False`（預設關，golden 逐位元不變）、`cyc_turn_lift`（髖膝固定倍率，§5 E1 掃 0.7／0.85／1.0 後定）。
- 開啟時：ABAD 與輪子力矩維持 `amp_t = clip(|wz|/1.3, 0.3, 1.2) × cyc_amp_turn`（轉速隨指令；訓練的 `cyc_amp_rand` 0.3–0.9 只作用在 ABAD 與輪）；髖膝改成 `cyc_turn_lift`，不隨 |wz| 也不隨隨機幅度縮。實作同平移：`sc_turn = [amp_t, lh, lk] / amp_t` 進 `blend`。
- policy 通道：`amp` 只乘 ABAD、`lift` 只乘髖膝（:717 那段），條件從 `ref["cyc_lat_decouple"]` 改成按族各自旗標（`wl` 混合）。
- 狗端 `gen_v3.py` 加同一分支（:202 附近）；影子跟跑釘住。

## 3. reward 與動作範圍

- `t_step` 開到旋轉族：`t_step = W_STEP · u4 · (wl · r_step_lat + (1−wl) · r_step_turn)`；`r_step_turn` 用 `step_apex_reward` 同式但目標 `STEP_APEX_TURN = 0.030` 固定（不隨 wz 縮）。`W_STEP` 沿用 2.5。
- `LIFT_NONNEG` 兩族都開（新鍵 `LIFT_NONNEG_ALL=True`；v3.7b 只開平移是為了配舊權重跑旋轉，v3.8 重訓無此限制）。
- `LIFT_SCALE` 由模組常數改為權重表鍵 `LIFT_SCALE`（預設 0.4 保 golden；`act_split` 讀 w），v3.8 設 0.6。
- 新懲罰 `t_sat = −W_SAT · Σ_12 |q_raw − clip(q_raw, lo, hi)|`（rad，hinge），預設 `W_SAT=0` 保 golden；v3.8 起點 2.0，由 §5 E3 攤帳定。
- 其餘沿用 W37B（`CYC_LAT_DECOUPLE`、`CMD_VY=(0.04,0.22)`、`CYC_LAT_FF`、`MIRROR_AUG`）。
