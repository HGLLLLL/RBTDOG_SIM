## 1. 連線

```bash
# 1) 連狗的 WiFi（現場沒有網路，出發前該裝的都要裝好）
# 2) RK3588（運控板）
ssh robot@192.168.234.1
# 3) Orin NX（應用板）—— 要先加一條路由才連得到
sudo ip route add 192.168.234.0/24 dev <wifi介面>
```

- **RK3588 = 運控板**，`/dev/shm/{joint_cmd, joint_state, imu_central}` 在這裡。
- **Orin NX = 應用板**，`/dev/shm` 裡只有 nvidia 的東西，**沒有任何運控相關**。
- 出發前先裝好 ssh 金鑰，現場一直打密碼很浪費時間。

## 2. ⚠️ 安全前提（依任務型態分兩類，缺一項就不要開始）

### 2.1 吊掛類（M5 腿關節、M8 擺動 —— 腿會動但不承重）

- [ ] 狗**用吊帶吊起**，機身**完全懸空**、四腿自由下垂不觸地
- [ ] **吊帶不可纏到腿**（症狀是「力矩接近上限但誤差不收斂」，很像伺服壞掉，其實是機構受阻）
- [ ] 16 顆馬達**全部零增益**（`kp = kd = effort = 0`）；做法是遙控器讓狗趴下／關運控
- [ ] 腿的擺動範圍內沒有人、沒有牆、沒有桌角

★ **判「腿有沒有真的自由懸掛」要拿摩擦死區當尺**，不要靠目視：
ABAD **±0.116** / HIP **±0.106** / KNEE **±0.314** rad（±6.7° / ±6.1° / **±18°**）。
**關節可以停在真平衡點 ±6°（膝 ±18°）內的任何位置。**
判「卡住」還是「機身歪」看**四腿是否同方向偏移**：同方向 = 姿態；單腿獨大 = 卡住。

### 2.2 承重類（M7 站立、M9 步態 —— 腿要撐住 41 kg）

- [ ] 吊帶掛成「**鬆弛但塌下來接得住**」—— 太緊會承重（量不到真實力矩），太鬆接不住
- [ ] ⚠️ **軟體保證不了「程式整個死掉」那條路**：controller 500 ms 後清零 →
      狗從 0.5 m 塌下來。**吊帶是唯一的安全網。**

### 2.3 兩類都一樣

- [ ] 急停鈕（機身鈕／遙控器 APP 紅色鈕）位置已確認、在手邊
- [ ] 電源開關位置已確認
- [ ] **至少一個人沒有在碰狗**，負責按急停
- [ ] ★ **第二個終端機已經開好、已經 ssh 進狗、游標停在急停指令上**：

```bash
sudo ~/estop_max.sh     # 殺我們的程式 → 確認死透 → 才解凍 mc_ctrl
```

## 4. ★ 中止語意：M5 型與 M7 型**相反**，別記錯

| | 中止時做什麼 | 為什麼 |
|---|---|---|
| **M5 型**（吊掛、不承重） | **純阻尼**（`kp = effort = 0`，只留 `kd`） | 腿空載，鬆手即可；完全洩力會讓腿砸到機械停點 |
| **M7 型**（承重） | **凍結目標角撐住** | 洩力＝狗直接塌下來 |

⚠️ 兩者的 `estop_max.sh` 是同一支（殺程式 → 解凍 `mc_ctrl`），
差別在**程式自己的中止路徑**。跑任何新腳本前先確認它是哪一型。

## 5. 現場最常踩的四個坑

| 坑 | 症狀 | 判別／處理 |
|---|---|---|
| **忘了寫心跳** | 指令寫進去了但馬達不動，讀回全 0 | `joint_cmd` base+0 的 u64 要以 ~1 kHz 更新；**先寫 payload、最後寫心跳** |
| **輪角讀數是包裹的** | 輪子轉超過半圈後角度差完全錯誤 | 用 `shm_io.wrap_pi` 逐步折回增量再累加 |
| **腿序搞混** | 命令了 A 腿卻是 B 腿動 | SHM 是 `fl, fr, bl, br`；動作設定檔是 `FR, FL, RR, RL`。**一律按名稱對應** |
| **增益引用錯模式** | 力矩／撓度對不上預期 | 原廠有兩組：**RL 設定檔** 60/120/120 kd1、**站立實測** 250 kd5。引用時一定要標明是哪一種 |

## 7. 快速對照：關鍵事實

| 事實 | 值 |
|---|---|
| `joint_cmd` 結構 | base=752、stride=112，`name[64]` + pos/vel/effort/kp/kd（f64） |
| `joint_state` 結構 | base=752、stride=120，+ temp/voltage，末尾 u64 `error` |
| `imu_central` | 數值自 **824** 起：acc[3]、gyro[3]、quat[4]（**xyzw，尚未實驗證實**） |
| 心跳 | `base+0` 的 u64，~1 kHz。不寫會被判過期而清零 |
| 逾時 | `joint_cmd_timeout: 500 ms` |
| 輪半徑 | 0.0961 m（碰撞網格實算） |
| 腿關節靜摩擦 | ABAD 1.85（**下界**）/ HIP 1.505 / KNEE 1.55 N·m |
| 輪摩擦 | 0.15 N·m 純庫倫 |
| `mc_ctrl` 可凍多久 | **實測 200 秒完全正常**（`M_freezetest.py`） |
