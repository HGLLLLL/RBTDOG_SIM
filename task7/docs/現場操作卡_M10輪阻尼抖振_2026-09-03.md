# 現場操作卡：M10 輪阻尼抖振測試（2026-09-03）

> **目的**：分辨 trip17 抖振（`wheel_kd=3.0`、64 Hz、刺耳聲）是
> **H1 driver 迴路不穩**（懸空也會抖 → kd=3.0 直接出局）還是
> **H2 地面黏滑**（懸空不抖 → 步態段還有機會上探）。
> 依據：`docs/F_trip17事故_輪阻尼抖振_2026-09-03.md`。
>
> **風險等級：低。** 墊高離地、腿全程洩力（一次都不上增益）、只給輪阻尼、
> 逐級升、一抖立刻歸零。與 M2（已跑過多次）同一種擺位。

---

## 1. 準備

1. **狗肚子墊高**（M2 的擺法），**四輪完全離地、可用手自由撥動**。
   ⚠️ 不要用吊帶吊——吊掛時左右輪會在機身正下方互相頂住（M5 實測），輪碰輪會污染測試。
2. 腿全程洩力，會自然垂著——正常，不要去扶。
3. 第二個終端機備 estop（雖然這測試連腿的增益都不碰）。
4. 推檔（M10 已加入清單）：
   ```bash
   bash task7/realbot/push_to_dog.sh     # 看到 M10_wheel_kd_chatter.py ✅
   ```

## 2. 乾跑

```bash
ssh robot@192.168.234.1
cd ~
python3 M10_wheel_kd_chatter.py
```

要看到：`✅ 結構檢查通過`、`✅ 16 顆全部洩力中`、`✅ mc_ctrl`、`[乾跑] 到此為止`。

## 3. 正式跑

```bash
sudo python3 M10_wheel_kd_chatter.py --confirm
```

每一級 kd（0.5 → 1.0 → 2.0 → 3.0）它會：

| 階段 | 你做什麼 |
|---|---|
| `① 靜置 5s` | **不要碰輪子**。看會不會自己抖起來（自激）|
| `② 撥輪 20s` | **依序輕撥四顆輪**（轉起來 3~5 rad/s 就夠，⚠️ 不要用力甩——kd=3 時煞車力矩=3×轉速，甩到 10 rad/s 就是 30 N·m）。看它是乾淨停下、還是振個不停。撥完按 Enter 提早進下一級 |

**一抖立刻自動歸零並停止升級**（用的是 trip17 資料驗證過的同一個偵測器,事故資料 0.23 秒觸發、五趟正常資料零誤報）。

## 4. 判讀（腳本會自己印結論）

| 結果 | 意義 | 下一步 |
|---|---|---|
| 某級**靜置自激** | **H1**：driver 迴路不穩，與地面無關 | 該 kd 出局。步態 kd 上限=懸空最高穩定級，回模擬重掃 `x_off`（kd 變了配平點就變）|
| 某級**受擾後停不下來** | 邊界不穩 | 同上，取前一級當上限 |
| **全部通過** | **H2**：trip17 的抖振需要地面（黏滑）才發生 | 下一步做「貼地不承重」版；或直接用 M9 的階段排程（起身 0.5）從步態 kd=1.0 上探 |
