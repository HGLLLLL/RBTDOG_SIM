# 現場操作卡：M11 輪子速度伺服系統辨識（2026-09-09）

> **目的**：量出輪子速度伺服的四個模擬器參數 —— 庫侖摩擦 τ_f、黏滯 b、延遲、時間常數（→ 慣量 J）——
> 加上速度量測雜訊與頻寬。這是「輪行模式」訓練的前置（同 H 文件的 +15 ms 伺服延遲之於腿）。
> **風險等級同 M10**：狗墊高、四輪離地空轉、腿全程洩力。輪子亂轉不會動到機身。
> 工具：狗上 `M11_wheel_sysid.py`；本機 `inference/wheel_sysid.py` 擬合。通用連線／安全見 `現場SOP_通用_2026-08-27.md`。

## 0. 已知事實（拿來對照今天的數字）

| | 值 | 來源 |
|---|---|---|
| 速度伺服式子 | τ = kd·(v_des − v) + τ_ff（kp = 0） | M2／M9 同一種寫法 |
| kd 上限 | **1.0**（2.0 懸空靜置自激，e 倍 50–64 ms） | M10，trip17 事故 |
| 純 kd 追蹤率 | 55–73%（v_des 0.3、kd 1.5、無前饋）；加 τ_ff 0.2 → 105% | 單顆馬達／四輪驅動 2026-08-25 |
| 滾動摩擦 | 0.13–0.23 N·m（單顆 0.213／0.225） | 同上 |
| 速度量測雜訊 | 47%（相對）、driver 有濾波 | H 文件 |
| 馬達規格 | 33 N·m、1200 RPM = 125.7 rad/s、輪半徑 0.09 m | 控制方式調查 |

M11 的保護：|v| > 8 rad/s（0.72 m/s）或 |τ| > 5 N·m 或抖振 → 全部歸零、解凍；Enter 隨時中止。

## 2. 現場準備

1. 狗肚子墊高，**四輪離地能用手自由撥動**；輪面貼膠帶（目視基準）。
2. 16 顆洩力（M0 檢查），腿不會動，但仍不要把手放在腿的行程內。
3. T2 終端機備 `sudo bash estop_max.sh`。
4. 狗上乾跑：

```bash
python3 M11_wheel_sysid.py --proto step --kd 0.5
```
要看到序列 20 段共 32 s、`✅ 16 顆全部洩力中`、`[乾跑]`。

## 3. 五個協定，依序跑（每個一趟，共 ≈ 2 分鐘的輪子轉動）

| # | 指令 | 秒 | 量什麼 | 現場看什麼 |
|---|---|---|---|---|
| ① | `sudo python3 M11_wheel_sysid.py --proto step --kd 0.5 --confirm` | 32 | 階躍：0→±0.5／1.5／3／5 rad/s | 每級 2 s 內速度到穩態；`v/τ` 印出的 τ 在 0.1–0.5 N·m |
| ② | `… --proto step --kd 1.0 --confirm` | 32 | 同上，kd 1.0 | 追蹤率應比 ① 高；**若有刺耳聲或 v 正負亂跳 → 程式會自己歸零，記下** |
| ③ | `… --proto ff --kd 0.5 --confirm` | 20 | 固定 1.5 rad/s，前饋 0／0.1／0.15／0.2／0.3 N·m | 穩態速度隨前饋線性上升；0.3 N·m 時可能過衝 |
| ④ | `… --proto chirp --kd 1.0 --confirm` | 22.5 | 掃頻 0.2→4 Hz、振幅 1.5 rad/s | 高頻時輪子跟不上是正常的，看它有沒有變成亂抖 |
| ⑤ | `… --proto noise --kd 0.5 --confirm` | 12.5 | 靜止 5 s、定速 2 rad/s 6 s | 只是安靜地量雜訊 |

② 若在第一級就抖振，**不要再試更高**，kd 1.0 就是上限；其餘協定照跑（都在 0.5 或已通過的 1.0）。
每趟結束畫面會印 `📊 ~/m_logs/M11_<時間>.json`。

## 4. 拉回本機、擬合

```bash
bash task7/realbot/pull_from_dog.sh trip20 'M11_*'
conda run -n rbtdog python task7/inference/wheel_sysid.py task7/logs/m_logs_trip20/M11_*.json --out task7/outputs/wheel_sysid_trip20.md
```

擬合會印每輪與四輪平均的：τ_f、b、延遲、τ_c、J、各級追蹤率、前饋斜率 1/(kd+b)、雜訊 std、頻寬。
**合理範圍**（不在裡面就先懷疑量測不是模型）：τ_f 0.1–0.3 N·m、b 0–0.05 N·m·s、延遲 5–30 ms、頻寬 > 3 Hz、
靜止 v_std < 0.1 rad/s。step 與 ff 兩個協定各自估的 τ_f 應在 ±0.05 內一致，不一致代表摩擦不是庫侖＋黏滯這麼簡單。

## 5. 這些數字之後去哪

- 模擬輪關節：`frictionloss = τ_f`、`damping = b`、`armature` 由 J 定；速度伺服照實機式子（kd ≤ 1.0 ＋ τ_ff）加延遲；obs 的輪速加 noise std。
- 訓練前的 G1 型檢查：模擬用同一個 M11 序列跑一次，四個參數要落回實測 ±20%。
- 下一步（另一張卡）：放回地面、腿站著承重，只給 vx 的「輪行模式」上機，那時才量得到打滑與承重下的摩擦。

## 6. 中止與異常

- 程式歸零並解凍後輪子會自由轉停；不要用手去煞。
- 抖振發生在 kd 1.0：記錄協定與時間，那就是這台的上限，回報後改用 0.5 做完剩下的協定。
- 某顆輪不轉（M5 時遇過 fl4 看不出轉）：看 log 的累積角度而不是眼睛，膠帶要貼。
