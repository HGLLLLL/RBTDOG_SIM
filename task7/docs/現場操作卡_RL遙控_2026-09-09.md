# 現場操作卡：RL 步態鍵盤遙控（`--teleop`，2026-09-09）

> 引擎＝CPG-RL v2.3（同 trip19），指令固定 vx 0.30。**按住 W 走、放開站好、空白鍵急停、站好時 Enter 收工。**
> 不綁吊帶前先確認：trip19 四趟 RL 零中止、Enter 停車六次全成功、急停路徑＝M9 既有中止（凍結目標角撐住）。
> 沒有側向與旋轉（v2.3 做不到，模擬驗過：vx 0 也照走 0.22 m/s、倒退指令照樣前進）。

## 0. 為什麼這樣設計

- 放開＝淡出到站姿（`--ramp` 秒，建議 2.0），不是原地踏步：不綁吊帶時「站著不動」最安全。
- 每次按 W 都是**新的一段**：淡入 `--ramp` 秒（policy 自己再淡入 1 s），走路中放開就從當下比例淡出。
- 按住的判定靠鍵盤自動重複：0.25 s 沒收到重複就當放開；剛按下有 0.7 s 寬限。
  **上機前在筆電打 `xset r rate 200 40`**（縮短重複延遲），否則輕點一下也會走 0.7 s。
- 空白鍵＝M9 中止路徑：當下目標角凍住、kp 250 撐著，畫面提示後按 Enter 依原路徑坐下。真正的硬體急停仍在 T2。
- `--walk-max` 是整個遙控段（含站著等）的逾時，逾時會自動淡出、升增益、等 Enter 坐下。承重上限 `--max-secs` 要一起放寬。

## 1. 推檔與乾跑

```bash
bash task7/realbot/push_to_dog.sh                      # M9_gait.py 有改，必推
```
狗上（T1）：

```bash
python3 M9_gait.py --traj A_kp250_walk.json --interactive --teleop \

```
要看到 RL policy 四行 ＋ `🎮 遙控：…`；沒有 ❌。

## 2. 上機

同上加 `sudo` 與 `--confirm`。流程：

1. 站起來 → READY（kp 250）→ **按 Enter** → 降增益 1.5 s → `TELEOP_STAND`（站著等鍵，畫面階段名）。
2. **按住 W**：`TELEOP_GAIT_IN`（2 s 淡入）→ `TELEOP_GAIT`（走）。放開 → `TELEOP_GAIT_OUT` → `TELEOP_STAND`。可重複。
3. 想收工：站好時**按 Enter** → 升增益 → STOPPED → 再按 Enter 坐下。走路中按 Enter 無效（先放開）。
4. **空白鍵**：任何時候都是急停。之後畫面提示 `[Enter] 依原路徑坐回趴姿`。
5. Ctrl-C 仍有效（＝放手，會塌）；只在狗已經趴著或有人扶著時用。

## 3. 第一趟怎麼走

- 第一段只按 1 秒就放開：看淡入→淡出→站好整個循環是不是乾淨、放開後多久停（應 ≈ 2 s）。
- 第二段按 3 秒。第三段按到場地邊放開。
- 每段之間狗站著時看 roll 有沒有回到 ±2° 內、膝力矩回到 ~17 N·m（站姿值）。
- 全程 policy 退回數應為 0（收工畫面 `policy：… 退回 0 步`）。

## 4. 中止或不對勁

- 空白鍵急停後狗撐著不會塌；先看四腿有沒有懸空，再按 Enter 坐下。
- 終端機字元怪掉（cbreak 沒還原）：打 `reset` 再 Enter。
- log 一樣在 `~/m_logs/M9_*.json`，`policy` 區塊是所有段合併；`inference/policy_log_summary.py` 照用。
