# 現場操作卡：站起來（M7）★★ 承重

**這是目前為止風險最高的一步。** 到 2026-08-26 為止所有實機測試都是**吊掛**的 ——
腿只撐自己的重量。這次腿要撐 41 kg。

- 對象：D1 Max 的 **RK3588**（`192.168.234.1`，帳號 `robot`）
- 物理擺放：**狗趴在地上**（不是吊掛），**吊帶掛著但鬆弛**
- 這張卡設計成**離線可用**

> ### ⚠️⚠️ 先看這個：軟體保證不了的事
>
> 我們的程式若**整個死掉**（kill -9、SSH 斷、Python 崩潰），
> controller 會在 **500 ms** 後把指令區清成 0 → **狗從站姿塌下來**。
>
> **軟體沒有辦法防止這件事。** 唯一的安全網是物理的：
> **吊帶必須掛著。** 它不承重（鬆弛），純粹是「萬一塌下來時接住」。
>
> 中止（保護觸發）不一樣 —— M7 的中止是**凍結目標角、維持增益、原地撐住**，
> 狗不會塌。但**程式死掉**不是中止，那條路走不到我們的程式碼。

---

## ⚠️ 安全前提（缺一項就不要開始）

### 1. 姿勢與安全網

- [ ] 狗**趴在地上**，16 顆洩力（遙控器讓它趴下／關閉運控）
- [ ] **吊帶掛著、鬆弛**、繫在能承 41 kg 的吊點上
      → 鬆到不承重（M7 才量得到真實力矩），但緊到塌下來時接得住
- [ ] 地面**平整、乾淨、不滑**。實測地面摩擦門檻約 0.4，一般地板沒問題
- [ ] 四周 1.5 m 內沒有人、沒有桌角

### 2. 人與急停

- [ ] **第二個終端機**已 ssh 進狗、游標停在 `sudo ~/estop_max.sh`
- [ ] 至少一個人**沒有在碰狗**
- [ ] 電源開關位置已確認

⚠️ 按下 estop 之後狗會在 **0.5 秒**後失力 —— 站著時那就是塌下來。
**estop 是最後手段，不是暫停鍵。**

### 3. 心理準備

| | 吊掛（前幾趟） | **這次** |
|---|---|---|
| 膝關節力矩 | 2.9 N·m | **42.45**（實機原廠實測） |
| 出事的後果 | 腿垂下去 | **41 kg 從 0.5 m 塌下來** |

## 1. 這次要複製什麼（全部有實機依據）

2026-08-26 15:47 錄下原廠自己從趴下站起來的全程
（`docs/原廠站立實測_全程錄製_2026-08-26.md`）。M7 照抄它：

| | 實機錄到的 | M7 |
|---|---|---|
| 增益 | 腿 kp **250** / kd **5.0**，純 PD 無前饋 | 一樣 |
| 軌跡 | 趴平 → **crouch** → **stand**，分段線性 | 一樣 |
| 中途路徑點 | **正是文件的 `crouch`**（12 關節 RMS 0.0000） | 一樣 |
| 起點 | `des` = 當下實測角（**無突跳**） | 一樣 |
| 增益上法 | **一步從 0 跳到 250** | **★ 我們用斜坡（2 秒）** |
| 輪子 | 位置保持（**解纏誤差**） | **★ 我們用純阻尼** |

**兩處刻意不照抄：**

1. **增益斜坡**：原廠一步跳到 250，代價是 ABAD/HIP 在那一瞬間衝到 **20–28 N·m**。
   斜坡爬升避開這個開啟衝擊，比原廠溫和。
2. **輪子純阻尼**：原廠是位置保持，但它用的是**解纏後的誤差**
   （實測：`kp×原始誤差 = 121 N·m`、`kp×解纏誤差 = −5.04`、實測 −5.07）。
   ⚠️ 天真地用原始誤差會下 **121 N·m** —— 輪子上限 40 的三倍，**而且方向相反**。
   我們不冒這個險。實測起身時輪子會滾 **1.14 rad**，
   **輪子必須能滾，鎖死的話腿伸不開。**

## 2. 力矩門檻

實機分段峰值 × 1.5：

| | ABAD | HIP | KNEE |
|---|---|---|---|
| 趴→crouch（實機峰值） | 28.15 | 22.70 | 35.41 |
| crouch **停住** | 22.23 | 21.34 | **33.62** |
| crouch→stand | 18.26 | 18.99 | **42.45** |
| 站穩 | 1.25 | 3.71 | 11.38 |
| **M7 門檻** | **45** | **40** | **65** |

硬上限 **120 N·m**（馬達規格 150），連續 2 筆即中止。

> ### ⚠️ 「只做到 crouch」比較安全，但不是因為力矩
>
> 停在 crouch 就要 **33.6 N·m**，跟全程峰值 42.45 差不多。
> 它降低的是**塌下來的高度**（0.29 m vs 0.51 m），**不是力矩**。
> 不要以為做 crouch 就沒事。

## 4. 逐階操作

### T0 — 乾跑（零風險，不需 sudo）

```bash
python3 M0_probe.py
python3 M7_standup.py --to crouch
python3 M7_standup.py --to stand
```

**要看到：**

| 輸出 | 預期 |
|---|---|
| `✅ 16 顆全部洩力中` | 必須。狗要趴著且洩力 |
| `✅ 機身姿態 roll … pitch …` | 趴著時應該接近 0（±5° 內） |
| `✅ 所有路徑點都在機構限位內` | 必須 |
| `⚠️ N 個關節的**起點**略微超出模型限位` | **正常** —— 趴著時膝頂在 ±2.80 的機械停點，模型是 ±2.801 |
| 力矩門檻 ABAD 45 / HIP 40 / KNEE 65 | 確認一下 |

**要停：**
- ❌ 起點超出限位 **> 0.05 rad** → 那不像機械停點，停下來檢查（M7 會自己擋）
- ❌ 趴著時 roll/pitch 就已經 > 10° → 地面不平或狗沒趴好

### T1 — 趴 → crouch → 趴

```bash
sudo python3 M7_standup.py --to crouch --confirm
```

總時長約 11 秒。**要看到：**

- 四條腿把身體撐離地面到約 **0.29 m**，停 2 秒，再坐回去
- 峰值力矩 **KNEE 30–40 / HIP 20–25 / ABAD 20–30** 量級（跟實機原廠同級）
- 結尾 `✅ 序列完整跑完`

**要停：**
- ❌ 任何 `⛔ 中止` → 照 §5 處理
- ❌ 機身歪斜（M7 在 ±25° 會自己中止）
- ❌ 峰值力矩 **遠低於** 20 N·m 而狗沒撐起來 → 指令沒被接受，看心跳

### ⛳ 回收點 1

```bash
bash task7/realbot/pull_from_dog.sh trip8 'M7_*'
```

**T1 過了才做 T2。** 把資料丟回來看過再決定。

### T2 — 趴 → crouch → stand → crouch → 趴

```bash
sudo python3 M7_standup.py --to stand --confirm
```

總時長約 15 秒。**要看到：**

- 狗**完整站起來**，機身約 **0.51 m**，維持 4 秒，再坐回去
- 峰值 KNEE 接近 **42**（實機原廠是 42.45）
- 站穩期間 KNEE 力矩掉到 **~10**

★ **站穩時的力矩應該只剩峰值的 1/4。** 若站著還維持 40，代表它在硬撐，
不是穩定站立 —— 停下來。

### T3（可選）— 站著不回來

```bash
sudo python3 M7_standup.py --to stand --stay --confirm
```

⚠️ **腿會一直承重**，直到你按 Enter 讓它坐回去。
只有在 T2 完全順利之後才做，而且**不要離開現場**。

## 5. 中止與復原 ★ 跟 M5 相反

### M7 中止時做什麼

```
保護觸發 → **凍結目標角、維持 kp** → 背景執行緒持續餵心跳
        → 印出中止前 12 筆原始序列
        → 停下來問你：坐回去，還是放手
        → mc_ctrl 保持凍結
```

★★ **M7 不會像 M5 那樣切成純阻尼。** 承重時放手＝狗塌下去。
中止時狗**還撐著**，你有時間看清楚再決定。

（若中止發生在 `RAMP_UP` 階段、kp 還很低，M7 會明說「尚未真正出力，
狗應該還在原本的趴姿」——那種情況不用緊張。）

### 你的兩個選項

| | 做什麼 | 後果 |
|---|---|---|
| **Enter** | 依原路徑**慢慢坐回趴姿**，再降增益 | ✅ 建議。狗回到起點 |
| **Ctrl-C** | 立刻放手 | ★ **狗會塌下去**。只有確定安全才用 |

### 收工後交還控制權

```bash
sudo kill -CONT <PID>      # PID 印在 M7 的輸出裡
python3 M0_probe.py        # 確認 16 顆回到 kp=kd=tau=0、mc_ctrl 是 S/R 不是 T
```

### 判讀表

| 現象 | 意思 | 怎麼做 |
|---|---|---|
| `力矩連續 N 筆超過 …` | 真的推不動，或撞到東西 | 🛑 看它印的原始序列。實測 τ **貼著** `kp\|e\|+kd\|v\|` = 我們的控制器在硬推 |
| 實測 τ **遠大於** `kp\|e\|+kd\|v\|` | 那力矩不是我們下的 | ⏸ 外力撞擊或感測尖峰。看同一刻位置有沒有變 |
| `機身傾角 … 超過 ±25°` | **狗在倒** | 🛑 最危險的一種。坐回去，檢查地面與吊帶 |
| `追蹤誤差 … 超過` | 腿跟不上目標角 | ⏸ 可能 kp 不夠或卡住。**不要直接調高 kp**，先看力矩 |
| 站穩時 KNEE 仍 > 30 | 在硬撐，不是穩定站立 | 🛑 坐回去 |
| 心跳遠低於 1000/s | 部分幀被判過期 | 🛑 這種狀態下承重很危險，停 |
