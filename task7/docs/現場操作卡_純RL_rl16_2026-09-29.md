# 現場操作卡：同事的純 RL 步態（rl16）首次上機 —— trip24

> **這趟的意義：狗第一次跑沒有 CPG 的純 RL policy** —— 53 維 obs、動作直接是 12 個 PD 目標＋4 個輪速、ONNX 轉 numpy（ELU）。
> 走的是 M9 既有的 `--v3` 流（產生器換成 `gen_direct`、obs 換成 `rl_obs_rl`），起身／增益過渡／護欄／退回全部沿用 trip22／23 驗過的殼。
> 退路＝零動作＝他的 default pose（站姿）。
> 介面盤點與模擬結果：`docs/results/S_純RL步態_MuJoCo重現_2026-09-29.md`；影子跟跑：`tests/test_policy_rl_closed_loop.py`。
> 通用連線／安全／中止語意：`docs/現場SOP_通用_2026-08-27.md`（**§2.2 承重類**一項都不能缺）。

**流程（每段一趟）**：站起來（kp 250，到他的 default pose：hip ±0.8／knee ∓1.5，機身約 0.49 m）→ 1.5 s 靜止過渡到 60/120/120 →〔Enter〕→ 走 →〔Enter〕→ 停 →〔Enter〕→ 趴下

## 1. 共同旗標

```bash
C="--v3 rl_only_2026-09-24_np.npz --interactive --no-mirror --kp 120 --kp-abad 60 --kd 1.0 --wheel-mode kd1 --wheel-kd 1.0 --vmax 18 --vcmd-max 16 --emax-abad 0.77 --emax 0.46 --tau-total 5 --wheel-vmax 30 --hold-max 15"
```

| 旗標 | 值 | 怎麼來的 |
|---|---|---|
| `--kp/--kp-abad/--kd` | 120／60／1.0 | 他的訓練致動器（IdealPD ABAD 60、HIP/KNEE 120、damping 1.0）；npz 記了同一組，不一致拒跑 |
| `--wheel-mode kd1 --wheel-kd 1.0` | | 他的輪 damping 1.0 ＝ 驅動器速度環 kd 1.0；effort 恆 0（訓練無摩擦補償） |
| `--no-mirror` | | 左右都訓過；M9 讀到 rl16 版面會自動關，帶著只是明講 |
| `--emax-abad` | **0.77** | 模擬 real 模式 ABAD 誤差峰 0.59（wz 0.5）× 1.3 |
| `--emax` | **0.46** | 髖膝誤差峰 0.35（延遲 1 步、vy 1.0）× 1.3；本卡指令範圍內峰 0.27 |
| `--vmax` | 18 | 關節速峰 10.6（擾動下）；規格 19.9 |
| `--vcmd-max` | 16 | 只在乾跑對零動作名目查（常數姿勢 → 0）；實走時 vy 1.0 命令速峰 18–20 超規格 → **本卡平移只到 0.5** |
| `--wheel-vmax` | 30 | 模擬輪速峰 14（vx 1.0） |
| `TMAX` | 50/50/70 不動 | 模擬峰 ABAD 44、髖 36、膝 57（擾動下） |

每段先乾跑（不帶 `--confirm`）再實跑；乾跑的 `--cmd`、`--walk-max` 要和實跑一樣。

## 3. 現場一定要記得的

0. `o`＋Enter ＝ 永久零動作（站姿）；空行 Enter 才是推進階段。
1. 指令時序同 v3：GAIT_IN 3 s cmd＝0 → 進 GAIT 後 1 s 才切到 `--cmd`。**指令切換那一步會有一次動作跳變**（模擬命令速峰 20 rad/s 就在這一步），`--vmax` 看的是量測速度（峰 3.7）不會誤中止。
2. **站姿比 v3.6f 矮 5 cm**（0.49 vs 0.54 m），吊帶高度照這個調；kp 120 下再下沉約 3 cm。
3. 動作無界：狗端夾 |a| ≤ 4、q_des 夾機構限位、每步變化 ≤ 0.5 rad。原地轉時 11–19% 步會被限位夾（模擬），`n_sat` 不是 0 是預期的。
4. 輪子 effort 恆 0（訓練無摩擦補償），輪速會比命令慢 0.13–0.2 rad/s，直走 0.3 看到 0.27–0.29 是正常的。
5. M9 其他護欄（傾角 20°、ChatterWatch、`--gap-max`、溫度）沒動；真正的急停在 T2。
6. **2026-09-30 的兩個 M9 小修**（trip23 發現，本趟第一次帶上狗）：`slow` 退回改量整步（讀 shm → obs → 推論 → 產生器）
   對 20 ms 週期，log 的 `fb` 出現 `slow:` 就是整步超過 20 ms（trip23 那種 11 ms 不會再被漏掉、也不會誤退回）；
   effort 讀值的**同號**孤立尖峰（兩側都跳 ≥ 30 N·m）現在也不進峰值表與 `--tau-total` 累計，收工表的「跳點」欄會比 trip23 多幾筆，正常。
