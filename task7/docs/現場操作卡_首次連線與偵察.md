# 現場操作卡：D1 Max 首次連線與唯讀偵察

**這張卡是給你在「沒有網路、沒有人可以問」的現場照著做的。**
建議先在有網路時把整份看過一遍，現場只要照著打。

- 對象：智元 D1 Max（`zsm-1w`）
- 這趟的目標：**確認底層控制介面開不開放**，順便把韌體版本等資料一次撈回
- 風險：**零**。全程唯讀，不 sudo 到狗上、不寫檔到狗上、不啟停行程、不送任何馬達指令
- 預計時間：15–25 分鐘

---

## 0. 出發前（在還有網路的時候做，很重要）

```bash
# 確認腳本在，而且語法沒問題
cd ~/rbtdog_sim
bash -n task7/realbot/recon_d1max.sh && echo OK

# 把這張卡印出來或另存到手機/桌面，現場沒網路時看得到
```

**心理準備**：連上狗的 WiFi 之後，你的電腦**會斷網**。
Claude、Google、任何線上資料都用不了。所有需要查的東西都在這張卡裡。

## 1. 連上狗的 WiFi

```bash
# 1-1 掃描（xxxxxx 是每台機器不同的序號，在機身標籤上也找得到）
nmcli dev wifi rescan
nmcli dev wifi list | grep -i XG2WIFI
```

記下完整 SSID，然後：

```bash
# 1-2 建立 profile
#     ★ never-default 與 ignore-auto-dns 這兩個不能省 —— 見下方「為什麼」
nmcli con add type wifi ifname wlan0 con-name d1max-wifi \
  ssid "XG2WIFI_xxxxxx" \
  wifi-sec.key-mgmt wpa-psk wifi-sec.psk "12345678" \
  ipv4.never-default yes ipv4.ignore-auto-dns yes ipv6.method disabled \
  connection.autoconnect no

# 1-3 連上
nmcli con up d1max-wifi
```

> **為什麼要 never-default**：狗的 DHCP 會發一個 gateway 給你，
> NetworkManager 預設會把 default route 和 DNS 整包搶過去。
> 這趟本來就要斷網，所以不設也能動 —— 但**回到有網路的地方時，
> 如果忘了關掉這個 profile，症狀會是「明明連著 WiFi 卻上不了網」**，
> 而且很難聯想到是這裡造成的。task6 為了同一個坑查了一整晚。設了就免疫。

驗證：

```bash
ip -br addr | grep wlan0     # 應該拿到 192.168.234.x
ping -c3 192.168.234.1       # 狗的 RK3588，要通
```

**通不了的話** → 跳到第 6 節「卡住了怎麼辦」。

---

## 2. 加一條路由，才連得到 Orin NX

D1 Max 有兩塊板，WiFi 只直通 RK3588。要連 Orin NX 得走這條
（官方文件 5.7）：

```bash
sudo ip route add 192.168.168.0/24 via 192.168.234.1

ping -c3 192.168.168.168     # RK3588（有線位址，走這條路由也通）
ping -c3 192.168.168.100     # Orin NX
```

這條路由是暫時的，重開機或斷線就沒了，不用手動清。

> Orin NX ping 不通不是災難 —— 主要目標（`rt/lowcmd`）兩塊板都會掃。
> 記下來繼續往下做就好。

---

## 3. 裝金鑰（省掉一直打密碼）

```bash
ssh-copy-id robot@192.168.234.1      # 密碼：bot
ssh-copy-id robot@192.168.168.100    # 密碼：1
```

**密碼別記錯**：RK3588 是 `bot`、Orin NX 是 `1`。

第一次連會問 `Are you sure you want to continue connecting?` → 打 `yes`。

裝不了也沒關係，腳本照樣能跑，只是每塊板要各打一次密碼。

> ⚠️ **不要用 `ssh dog`**。那是 `~/.ssh/config` 裡給 D1 EDU 的別名
> （指向 `192.168.168.168`、使用者 `firefly`）。兩台狗的有線 IP 剛好一樣但帳號不同，
> 打過去會用錯的帳號。這台一律用 `ssh robot@<ip>` 完整寫。

## 4. 跑偵察腳本

```bash
cd ~/rbtdog_sim
bash task7/realbot/recon_d1max.sh
```

不帶參數就是 WiFi 模式，預設 `RK=192.168.234.1`、`NX=192.168.168.100`，正是你現在的狀況。

**跑多久**：兩塊板各 1–3 分鐘。ROS2 的查詢有 30 秒逾時保護，卡住會自己跳過。

**它會做什麼**（全部唯讀）：

| 區段 | 內容 |
|---|---|
| 本機預檢 | 介面、路由、路由有沒有加對、ping、ARP |
| 身分 | hostname、uname、OS |
| ★ 韌體版本 | `/opt/release/version.yaml`（兩塊板） |
| ★★ 共享記憶體 | `/dev/shm/` 完整列表 → 找 `spline_shm` |
| 行程 | 運控相關行程、CPU 前 20 名 |
| 監聽埠 | `ss -lntup` |
| 狗自己的網路 | `ip addr` / `ip route` |
| robot-launch | 節點管理工具 |
| 檔案系統 | `/opt` 結構、搜尋 `lowcmd`/`lowstate`/`spline`/`lowlevel` 字樣的檔案 |
| ★★★ ROS2 | env、topic 全表、node 全表、**底層 topic 的型別與 msg 定義**、自訂 msg 清單 |

最後會印一段**自動判讀**，直接告訴你路線 B / C 有沒有命中。

## 6. 卡住了怎麼辦（現場沒網路可查，都寫在這）

### 連不上 WiFi

- SSID 打錯：`nmcli dev wifi list` 再確認一次，`XG2WIFI_` 後面的序號每台不同
- 密碼是 `12345678`（官方文件明載）。若被改過，機身標籤或找售後
- 狗沒開機 / 還在啟動：等 1–2 分鐘再掃
- `nmcli con delete d1max-wifi` 然後重建一次

### 連上 WiFi 但 ping 不到 192.168.234.1

```bash
ip -br addr | grep wlan0      # 有沒有拿到 192.168.234.x？沒有就是 DHCP 沒成功
ip neigh | grep 192.168.234   # 有 MAC 代表實體層通，是上層問題
```

- 沒拿到 IP → `nmcli con down d1max-wifi && nmcli con up d1max-wifi`
- 狗的網口**可能沒有 LED**（D1 EDU 是這樣），別靠燈判斷

### ssh 連得上但密碼被拒

RK3588 = `bot`、Orin NX = `1`。兩個都試過還不行，就記下現象、跳過那塊板。

### ROS2 topic list 是空的

**這不代表沒有 topic。** 可能是：
- `ROS_DOMAIN_ID` 或 `RMW_IMPLEMENTATION` 沒設對（腳本會把 `/opt/runtime/env.bash` 整份撈回來，回去再判讀）
- 運控在 RK 板內用自己的 DDS，NX 上看不到
- zenoh router 沒起來

**不要在現場花時間 debug 這個。** 把 env 那段帶回來就好。

### 腳本跑到一半卡住

`Ctrl-C` 中斷。已經寫出來的 `rk3588.log` / `orinnx.log` 仍然有效，帶回來。

### 完全連不上，想放棄這趟

先做這一件事就有價值 —— 只要能 ssh 進去：

```bash
ssh robot@192.168.234.1 'cat /opt/release/version.yaml; ls -l /dev/shm/'
```

**韌體版本 + `/dev/shm` 列表**，這兩樣就足以決定下一步。

## 7. 這趟要回答的三個問題（心裡先有底）

1. **`ros2 topic list` 裡有沒有 `rt/lowcmd` / `rt/lowstate`？**
   有 → 底層可寫，部署路線當場定案（同家族的 D1 MaxPro 就是這個介面：
   可下 `q_des` / `kp` / `kd` / `tau_ff`）
2. **`/dev/shm/` 裡有沒有 `spline_shm`？**
   有 → 第二條路，可沿用 task6 在 D1 EDU 上驗證過的做法
3. **兩塊板的韌體版本是多少？**
   拿去對照 SDK README 的相容表，決定要用 0.1.1 還是 0.2.1

三個都是唯讀就能回答的。**這趟不要試圖送任何指令給狗。**
