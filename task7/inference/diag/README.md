★ 這些不是常設工具，沒有測試。留著是因為**量法本身**值得重用：

## 兩個量法上的坑（別重踩）

1. **擺動相判定**用 `duty_remap` 後的 `sin(th) > 0`（軌跡公式自己的定義），
   不要用離地高度門檻 —— 那在會彈跳的步態上會騙人。
2. **輪角讀數是包裹的**（`[−π, π]`）。轉超過半圈直接相減會得到完全錯誤的值，
   要逐步折回增量再累加（與 `realbot/shm_io.wrap_pi`、`Trace.yaw_total` 同一個坑）。

前腳的近垂直尖峰 + 貼地水平線 = 被拖著走。
