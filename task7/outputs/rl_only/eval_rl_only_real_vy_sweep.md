狗上指令切換後第一步的 `a_raw` 與模擬第一步逐維相差 < 0.1（numpy 版與 ONNX 對得上）。

結論：
- **|vy| ≤ 0.3 是死區**，0.35 起才踏步；0.4 以上實測 ≈ 指令 × 0.7 − 0.07。vx 沒這問題（純輪行，0.3 狗上正常）。
- 訓練端的解釋（`RL_only/*_env.yaml`）：`track_lin_vel_xy_exp` 的 std 0.5，vy 0.3 完全不動仍拿到 exp(−0.36) ≈ 70% 的追蹤獎勵，
  而踏步要付關節偏差／動作變化的代價 → policy 學到「小側向指令不值得動」。`command_threshold 0.1` 只管站立獎勵的縮放，不是這個門檻。
- 護欄用量到 0.6 都在操作卡範圍內（ABAD 誤差 ≤ 0.33 < 0.77、命令速峰 ≤ 9.9 < 16）。
